族谱系统-册谱模块前端设计文档（UI&交互&架构）
文档版本：V1.0
适配项目：族谱Web端/移动端H5项目（树谱+册谱双视图）
关联文档：册谱产品需求PRD、树谱前端设计文档
核心定位：本文档为前端专属落地文档，不重复业务需求，只定义：页面结构、组件拆分、渲染规则、样式规范、交互逻辑、联动机制、适配方案、兼容细节、报错UI。
核心设计思想：一册双态、数据同源、视图隔离。底层复用人物数据源，册谱专注书籍阅读、文档排版、印刷级输出，与可视化树谱形成功能互补。
一、模块整体前端架构设计
1.1 整体页面结构（固定四分区）
册谱页面采用经典书籍文档布局，区别于树谱的全屏画布布局，结构固定，适配阅读和排版：
- 顶部导航栏（Global Header）：全局操作、导出、搜索、视图切换
- 左侧卷宗目录侧边栏（Sidebar）：卷册导航、折叠展开、快速跳转
- 中间主内容区（Main Content）：册谱正文渲染核心区域
- 底部Tab栏（Tab Bar）：树谱 / 册谱 / 我的 全局切换（与树谱共用）
1.2 前端数据流转架构（核心约束）
严格遵循：只读渲染+配置驱动
1. 人物基础数据：统一从后端人物接口获取，不本地缓存、不独立存储
2. 册谱个性化配置：前端缓存+后端存储（卷序、排版模式、过滤规则、显示开关）
3. 视图渲染：根据配置参数，动态渲染苏式/欧式排版、过滤节点、卷宗内容
4. 数据联动：人物数据更新后，册谱页面自动重载渲染，无需手动刷新卷宗
1.3 核心组件拆分（可直接用于开发）
组件高解耦，支持单独复用、迭代、维护：
- BookHeader：册谱顶部操作栏组件
- BookSidebar：左侧卷宗目录组件（支持层级、折叠、高亮）
- BookLayout：册谱整体布局容器（适配PC/移动端）
- BookArticle：纯文本卷宗渲染组件（谱序、祖训、凡例）
- BookFamilyList：世录自动渲染组件（核心组件，渲染所有人物条目）
- BookFilter：册谱专属过滤配置组件
- BookExport：PDF/Word导出组件（含进度交互）
- PersonPop：人物详情弹窗（树谱/册谱共用）
- LinkToTree：跳转到树谱定位组件
二、页面分区详细前端设计
2.1 顶部操作栏 BookHeader 设计
UI样式：浅底色简约导航栏，分割线区分，功能按钮分组展示
固定功能按钮（PC端）：
- 全文搜索：输入框+搜索按钮，支持关键词高亮、段落定位
- 排版切换：苏式传记 / 欧式世系 切换按钮（单选切换）
- 视图过滤：下拉面板（隐藏妻子/女儿/女婿、隐藏夭折人员）
- 编辑卷宗：管理员专属按钮，普通用户隐藏
- 导出功能：下拉菜单（整本PDF、单卷PDF、Word导出）
- 刷新视图：重置渲染、清除缓存
移动端适配：功能按钮收纳为「更多」下拉菜单，保留搜索、导出核心按钮
2.2 左侧目录侧边栏 BookSidebar 设计
UI形态：PC端常驻展开，移动端可收起/弹出抽屉
目录结构：严格按照后端卷宗排序渲染，支持层级展示
- 卷标题高亮：当前阅读卷高亮蓝色字体
- 点击跳转：点击目录项，主内容区滚动至对应卷首
- 折叠功能：支持折叠非当前卷，简化视图
- 卷类型标识：文档卷/世录卷 小标签区分展示
2.3 主内容区 BookArticle / BookFamilyList 核心设计
2.3.1 通用书籍样式规范（印刷级样式）
- 页面底色：象牙白（#FDFBF5），护眼纸质质感，区别于系统纯白
- 正文字体：PC端宋体/思源宋体，移动端默认清晰衬线字体
- 字号规范：标题20px、二级标题16px、正文14px、注释12px
- 行间距：1.8倍行高，适配长篇阅读，符合传统族谱排版习惯
- 段落间距：段落首行缩进2字符，标题居中对齐
2.3.2 文档卷渲染规则（谱序、祖训、艺文）
- 支持富文本完整渲染：文字、图片、换行、分段、加粗、居中
- 图片自适应：图片最大宽度100%，自动居中，防止溢出
- 无固定格式限制，完全保留管理员编辑的排版样式
2.3.3 世录卷自动渲染规则（核心前端逻辑）
无需手动排版，前端根据人物数据+配置自动生成整本世录
排序逻辑（前端执行）：
1. 优先按辈分降序（祖辈在前，晚辈在后）
2. 同辈按长幼排行升序（老大在前，老小在后）
3. 同一人物，配偶、子嗣紧随其后排列
三、两种排版模式前端渲染细节（重点区分）
3.1 苏式排版（默认主推）
形态：纯段落流式传记，完全复刻传统老族谱文字风格
渲染规则：
- 单人一条完整段落，整合排行、姓名、字号、生卒、葬地、配偶、子女、传记
- 无表格、无格子，纯文本接续排版
- 文字连贯，适合OCR旧谱对接、出书印刷
- 支持超长传记自动换行、分页
3.2 欧式排版（备选模式）
形态：世代对齐表格式排版，层级清晰、辈分直观
渲染规则：
- 按世代分行对齐，同辈人物横向排布
- 单人物格子展示基础信息，传记可点击展开
- 适合新手阅读，快速区分辈分分支
四、交互逻辑前端设计（全部可落地细节）
4.1 人物双向联动交互（树谱↔册谱）
1. 册谱跳转树谱：点击人物姓名，弹窗出现「查看树谱位置」按钮，点击后自动切换Tab至树谱，目标节点居中高亮、自动缩放聚焦
2. 树谱跳转册谱：树谱卡片点击「查看册谱」，自动切换Tab至册谱，页面滚动定位到该人物世录段落，文字闪烁高亮2秒
4.2 全文搜索交互
- 支持匹配：姓名、生卒、籍贯、传记关键词
- 搜索结果列表展示：所属卷名+段落预览
- 点击结果自动定位，关键词红色高亮标记
- 支持上一条/下一条结果切换
4.3 过滤开关实时渲染交互
开关切换无刷新页面，前端动态重渲染世录内容：
- 隐藏妻子：过滤所有配偶条目
- 隐藏女儿：过滤本族女性后代世录
- 隐藏女婿：过滤女性配偶记录
- 隐藏夭折：过滤标记为早夭的人物条目
过滤仅控制视图展示，不修改原始数据，关闭开关立即恢复展示
4.4 翻页与阅读交互
- 支持鼠标滚轮连续滚动阅读，模拟翻书流畅度
- 顶部悬浮页码提示，实时显示当前阅读卷、位置
- 一键回到顶部、一键回到卷首
五、导出功能前端交互设计
5.1 PDF导出核心交互
- 导出加载态：显示进度条「正在排版渲染PDF」，禁止重复点击
- 导出配置弹窗：支持选择是否导出图片、批注、隐藏过滤内容
- 整本PDF：按卷宗顺序完整拼接，保留所有排版样式
- 单卷PDF：仅导出当前选中卷宗内容
5.2 Word导出
前端排版结构同步输出，保留段落、标题、图片、人物格式，支持线下二次编辑
六、适配方案（PC + 移动端H5）
6.1 PC端（≥1200px）
- 侧边栏常驻，左右分栏布局
- 正文固定最大宽度，居中展示，两侧留白，模拟书籍阅读体验
- 所有功能按钮平铺展示
6.2 平板端（768px-1200px）
- 侧边栏默认收起，点击展开抽屉
- 功能按钮部分收纳至更多菜单
6.3 手机端（<768px）
- 全屏阅读模式，隐藏多余布局
- 字体自适应缩放，行高自适应
- 禁止横向滚动，所有内容竖向适配
- 人物弹窗全屏展示，方便移动端操作
七、异常状态UI设计
所有异常均做友好UI兜底，不白屏、不报错崩溃：
- 无卷宗数据：空状态图文提示「暂无册谱卷宗，请管理员创建卷册内容」
- 无人物数据：空状态提示「暂无族人数据，请添加家族成员」
- 加载中：全局骨架屏，模拟书籍加载样式
- 数据加载失败：重试按钮+错误提示文案
- 无搜索结果：空白提示「未匹配到相关内容」

九、前端开发落地注意事项
1. 严禁双数据源：册谱绝不单独维护人物数据，所有人物渲染依赖统一接口
2. 样式印刷兼容：PDF导出样式与页面预览样式保持一致，杜绝预览正常、导出错乱
3. 生僻字兼容：引入思源宋体/仿古字体，解决族谱生僻字乱码问题
4. 渲染性能优化：千人级数据采用虚拟列表渲染，避免DOM节点过多卡顿
5. 权限视图隔离：普通用户隐藏编辑按钮，仅管理员可见卷宗编辑功能
