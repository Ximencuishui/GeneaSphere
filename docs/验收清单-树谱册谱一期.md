## K. 集成审计（2026-08-20）

**路由影响面**：本轮唯一路由改动是 `/cepu/:clanId` 移除 `requiresAuth`（支持分享链接匿名访问）。其余页面引用全部仍然有效：管理后台"概况→册谱"（`/cepu/:slug`）、家族详情页"查看册谱"、树谱详情"查看册谱"（`/cepu/:id?person=`）均正常；无页面依赖被移除的鉴权元信息。

**审计发现并修复的集成缺口**：
1. **分享 token 未透传**：CepuPage 的读调用未携带 `?share=`，匿名分享用户会 403 → 已修：`cepuApi.getVolumes/getVolume/search/getPersonBio/exportPdfUrl/exportWordUrl` 全部支持 share 参数透传。
2. **分享可读范围不全**：person-bio、PDF、Word 导出原为登录专属 → 已开放给有效分享 token（只读，写仍被拒）。
3. **批注调用在匿名分享模式误触发** → `loadAnnotations` 按 `hasLogin` 门控。
4. **JWT 过期语义回归**：分享守卫原把无效 token 当无凭证返回 403 → 改为带 token 但无效时返回 401（与全局守卫一致，前端可跳登录）。
5. 分享匿名模式：隐藏"查看树谱位置"（树谱页需登录）、隐藏编辑/分享/版本历史入口。

**验证（真库冒烟）**：分享集成 8/8（卷宗/世录/检索/传记/Word 103KB/PDF 622KB 全 200 + 列表分享/写批注仍 401）；守卫 4/4（无凭证 403 / 坏 token 401 / 有效 JWT 200 / 分享 200）。
