# 树谱模块‑需求文档（PRD）
文档版本：V1.0
适用项目：族谱Web网站项目
关联模块：册谱模块、人物数据模块、导入导出模块
> 说明：树谱为**同一套人物业务数据的可视化视图**，不独立存储业务数据；所有人物数据来源于【人物主数据库】，树谱仅做渲染、交互、过滤操作。

## 1、模块概述
### 1.1 产品目标
树谱（世系树/吊线图），模拟传统家谱吊线图，图形化展示家族血缘、婚姻、代际辈分关系。
面向两类用户：
1）普通家族成员：快速查找自己的祖先、同辈、后代，看懂家族分支脉络；
2）修谱管理员：预览世系结构，校验父子婚配关系是否录入错误，导出世系大图用于印刷。

> 树谱定位：**重关系展示，轻文本内容**；大段传记、谱序、墓志交由【册谱模块】承载。

### 1.2 相关术语
- 树谱：世系可视化视图，数字化吊线图
- 节点：人物卡片（男性/女性）
- 辈分：同一世代的人物集合，横向排布
- 房派：家族分支
- 配偶节点：妻、妾、继配、驸马等
- 导出完整PDF：整张超长世系吊线大图
- 导出分页PDF：拆分页面，适配打印
- 过滤开关：隐藏妻子、女儿、女婿（兼容传统族谱习惯）

## 2、功能需求
### 2.1 视图基础渲染
1. 数据源：读取人物表、配偶关系表；**树谱不保存独立副本，修改人物数据后树谱自动刷新**。
2. 布局模式：默认横向世系树（父在上，子女向下展开），支持可选纵向模式。
3. 节点配色规范
    - 男性节点：蓝色卡片，标识【夫】，展示排行、姓名、生卒信息；
    - 女性节点：红色卡片，标识【妻 / 妾 / 女】，展示排行、姓名、生卒信息。
4. 连线规则
    - 水平连线：婚姻配对关系；
    - 垂直向下连线：父子血缘生育关系；
    - 支持一人多配偶：多个配偶节点并排，分别向下生成分支子女；
    - 支持过继、收养关系，提供虚线标识区分亲生与过继。
5. 一夫多配偶场景下的走线规则（新增）
    - **婚姻汇聚点**：在丈夫节点正下方设置一个虚拟的婚姻汇聚点，丈夫到汇聚点使用短垂线；
    - **分岔到各配偶**：从汇聚点水平分岔到每一位配偶节点正上方，再垂直连入配偶节点顶部；
    - **妻子分支独立着色**：每位妻子的分支（妻子节点描边、妻子→子女边、婚姻分岔水平段）使用统一颜色，同一妻子在所有视图下颜色保持一致；
    - **子女归属清晰**：吊线图模式下，子女直接挂到对应妻子节点下方；其他模式下，子女仍挂在丈夫节点下方，但需通过视觉标识（颜色/虚线/标注）区分生母；
    - **避免连线交叉**：同一丈夫的多条婚姻线水平段必须在不同 Y 坐标错开，或采用梳状布线统一汇聚后分岔，禁止多条婚姻线在同一水平段重叠。
6. 节点卡片展示字段（树谱卡片只展示精简字段）
> 卡片内字段：身份标识、排行、姓名、生卒年；**传记、葬地、功名不在卡片展示**。

### 2.2 画布交互能力
1. 缩放：鼠标滚轮缩放画布；移动端双指缩放。
2. 平移拖拽：按住画布拖动，浏览庞大家族树。
3. 节点点击事件
    - 单击人物卡片：弹出人物详情弹窗，可查看完整信息，跳转编辑人物，可跳转册谱定位该人物记录；
4. 折叠/展开分支
    - 每个房派分支支持折叠，折叠后隐藏该分支全部后代；解决人物数量巨大画布臃肿。
5. 定位到本人：一键聚焦当前登录用户在树谱中的位置，画布自动居中。

### 2.3 顶部工具栏功能
|功能项|需求描述|
|---|---|
|添加成员|弹出新增人物表单，录入完成后自动刷新树谱视图|
|搜索成员|弹窗输入姓名，搜索匹配人物，画布自动滚动、缩放到目标人物节点高亮|
|刷新视图|重新读取数据库，重绘全部树谱，修复连线错乱问题|
|导入JSON|读取族谱JSON文件，批量写入人物库，刷新树谱|
|导入Excel|解析族谱Excel模板，批量导入人物，数据校验后刷新视图|
|导出JSON|导出全家族原始人物数据，用于备份、迁移到其他族谱系统|
|导出分页PDF|分页切割世系图，文件大小可控，适配打印机打印吊线图|
|导出完整PDF|输出一张完整超长大图PDF，用于印刷世系挂画，增加文件大小提示|

### 2.4 人物节点过滤开关（重要，适配传统族谱）
三个独立开关，可自由组合勾选，实时生效，切换后画布立刻重绘：
1. 隐藏妻子：隐藏所有男性的配偶节点；
2. 隐藏女儿：隐藏本族女性后代（女儿）；
3. 隐藏女婿：隐藏女儿的配偶。

> 默认全部不开启，完整展示全部亲属；传统修谱用户可以一键开启，只显示本族男性族人。

### 2.5 特殊家谱业务场景适配
1. 一人多配偶：支持多妻/妾，配偶节点按婚姻顺序水平排列在丈夫右侧；各自子女分支独立连线或独立着色区分；婚姻线采用汇聚点分岔，避免多条连线重叠；
2. 过继、兼祧：支持标记，血缘使用虚线；
3. 无子女：节点不向下生成连线；
4. 未婚无配偶：不渲染配偶卡片；
5. 离异、早夭：人物卡片可做标记标签。

### 2.6 与册谱模块联动
1. 在树谱点击人物卡片，支持【跳转到册谱】，直接定位到此人物的册谱文本记录；
2. 底层共用同一人物数据库：在册谱修改人物，树谱自动同步；树谱新增人物，册谱同步出现记录；**禁止两套独立数据存储**。

### 2.7 布局防重叠与牵引线优化规则（新增）
#### 2.7.1 同世代卡片不重叠
1. **节点外接矩形碰撞检测**：每个节点按卡片宽度和高度计算外接矩形，任意两个节点的水平间距 ≥ `nodeSep`，垂直间距 ≥ `rankSep`；
2. **同代节点 Y 坐标对齐**：同一世代（generation 相同）的节点，Y 坐标必须完全一致，保证辈分横线清晰；
3. **子树整体宽度预留**：布局父节点时，必须按所有子树的外接矩形宽度预留空间，不能只用节点自身宽度估算；
4. **配偶子树参与整体布局**：配偶节点及其下方继子女子树不能独立于主树布局，必须作为「子树外接矩形」一并参与碰撞检测。

#### 2.7.2 配偶子树整体避让
1. **有效子树宽度**：每位配偶占用的水平空间 = `max(配偶卡片宽度, 该配偶下方子树总宽度)`；
2. **配偶顺序排列**：配偶按 `marriage_order` 从左到右排列在丈夫右侧，相邻配偶间距 ≥ `spouseGap`；
3. **继子女居中布局**：每位配偶下方的子女以配偶正下方为中心水平排列，子女之间间距 ≥ `nodeSep`；
4. **跨子树防重叠**：当某配偶的子树宽度超出其卡片宽度时，后续配偶及丈夫其他分支必须整体右移，避免与子树重叠。

#### 2.7.3 牵引线不重叠（梳状布线）
1. **单子女 L 形**：父节点底部中心 → 子节点顶部中心，先垂直向下再水平（如需）；
2. **多子女 T 形**：父节点底部中心垂直向下到分支横线，再水平分岔到各子节点顶部，所有子节点共享同一条水平分支线；
3. **一夫多妻婚姻线**：丈夫节点底部中心 → 婚姻汇聚点 → 各配偶顶部中心；汇聚点到配偶的水平段按配偶顺序在同一水平线上依次分岔，禁止重叠；
4. **同层边水平段错开**：如果同一 Y 层存在多条水平边（如多位丈夫的多条婚姻线），必须通过微调 Y 坐标或不同水平层错开，避免线段重合；
5. **禁止斜线**：所有牵引线必须是水平或垂直的正交线段，不允许斜向连线。

#### 2.7.4 跨房派边交叉最小化
1. **子节点按重心排序**：同一父节点的子节点，按各自子树的水平重心从小到大从左到右排列，减少长距离边交叉；
2. **主脉子节点居中**：主脉子节点优先放置在子节点序列的中间位置，使主脉垂直线自然居中；
3. **长边绕行**：当两个房派分支的边必须交叉时，允许引入额外的折点（一般不超过 2 个）让连线从节点间隙绕行。

## 3、非功能需求
### 3.1 性能
1. 单棵族谱，500人物以内，画布渲染流畅；
2. 超过1000人物，提示用户建议开启分支折叠，避免卡顿；
3. 大数据量禁止一次性渲染全部节点，可实现可视区域懒加载。

### 3.2 兼容性
1. Web端：Chrome、Edge主流浏览器适配；
2. 移动端H5：支持触摸缩放、拖拽；小屏幕布局自适应。

### 3.3 异常处理
1. 父子关系循环错误（A的父亲是B，B的父亲是A）：检测循环数据，弹窗提示用户，不崩溃画布；
2. 关系缺失数据：缺少父亲ID的顶层祖先，放置在树谱最顶层；
3. 导入数据格式错误：给出错误明细，不污染现有族谱数据。

## 4、页面UI原型简要说明
1. 顶部：操作工具栏按钮组；
2. 主体区域：树谱可视化画布（滚动缩放区域）；
3. 底部Tab切换栏：【树谱 | 册谱 | 设置】，点击切换模块。

## 5、输入输出
- **输入源**：人物主表、配偶关联表、过继关系表
- **输出**：可视化树谱界面、JSON备份文件、PDF文件
- **跳转输出**：人物编辑弹窗、册谱页面定位

## 7、验收标准
1. 修改人物数据，树谱实时更新，和册谱数据保持完全一致；
2. 过滤开关可以正确隐藏对应女性节点；
3. 多配偶、过继关系可以正确渲染连线；
4. 导入导出后，重新打开树谱，人物关系完整无丢失；
5. 出现循环血缘数据，页面不崩溃，给出提示；
6. **一夫多妻场景**：同一丈夫的多位妻子节点水平并排，不重叠，且各自分支使用统一颜色区分（新增）；
7. **婚姻线走线**：丈夫到多位妻子的连线采用汇聚点分岔或梳状布线，多条婚姻线不重叠、不重合（新增）；
8. **同世代卡片不重叠**：任意两个节点的外接矩形水平间距 ≥ `nodeSep`，垂直间距 ≥ `rankSep`，1000 节点场景下肉眼不可见重叠（新增）；
9. **牵引线不重叠**：同一父节点到多个子女的 T 形分支线共享一条水平段；同一 Y 层的多条婚姻线/分支线通过错开 Y 坐标避免重合（新增）；
10. **配偶子树避让**：妻子下方的继子女子树与丈夫其他分支、其他妻子子树之间无重叠（新增）；
11. **正交连线**：所有父子、夫妻关系牵引线均为水平或垂直线段，无斜线（新增）。
