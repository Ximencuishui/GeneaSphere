# 树谱模块‑需求文档（PRD）
文档版本：V1.0
适用项目：族谱Web网站项目
关联模块：册谱模块、人物数据模块、导入导出模块
> 说明：树谱为**同一套人物业务数据的可视化视图**，不独立存储业务数据；所有人物数据来源于【人物主数据库】，树谱仅做渲染、交互、过滤操作。

## 1、模块概述
### 1.1 产品目标
树谱（世系树/吊线图），模拟传统家谱吊线图，图形化展示家族血缘、婚姻、代际辈分关系。
面向两类用户：
1）普通家族成员：快速查找自己的祖先、同辈、后代，看懂家族分支脉络；
2）修谱管理员：预览世系结构，校验父子婚配关系是否录入错误，导出世系大图用于印刷。

> 树谱定位：**重关系展示，轻文本内容**；大段传记、谱序、墓志交由【册谱模块】承载。

### 1.2 相关术语
- 树谱：世系可视化视图，数字化吊线图
- 节点：人物卡片（男性/女性）
- 辈分：同一世代的人物集合，横向排布
- 房派：家族分支
- 配偶节点：妻、妾、继配、驸马等
- 导出完整PDF：整张超长世系吊线大图
- 导出分页PDF：拆分页面，适配打印
- 过滤开关：隐藏妻子、女儿、女婿（兼容传统族谱习惯）

## 2、功能需求
### 2.1 视图基础渲染
1. 数据源：读取人物表、配偶关系表；**树谱不保存独立副本，修改人物数据后树谱自动刷新**。
2. 布局模式：默认横向世系树（父在上，子女向下展开），支持可选纵向模式。
3. 节点配色规范
    - 男性节点：蓝色卡片，标识【夫】，展示排行、姓名、生卒信息；
    - 女性节点：红色卡片，标识【妻 / 妾 / 女】，展示排行、姓名、生卒信息。
4. 连线规则
    - 水平连线：婚姻配对关系；
    - 垂直向下连线：父子血缘生育关系；
    - 支持一人多配偶：多个配偶节点并排，分别向下生成分支子女；
    - 支持过继、收养关系，提供虚线标识区分亲生与过继。
5. 节点卡片展示字段（树谱卡片只展示精简字段）
> 卡片内字段：身份标识、排行、姓名、生卒年；**传记、葬地、功名不在卡片展示**。

### 2.2 画布交互能力
1. 缩放：鼠标滚轮缩放画布；移动端双指缩放。
2. 平移拖拽：按住画布拖动，浏览庞大家族树。
3. 节点点击事件
    - 单击人物卡片：弹出人物详情弹窗，可查看完整信息，跳转编辑人物，可跳转册谱定位该人物记录；
4. 折叠/展开分支
    - 每个房派分支支持折叠，折叠后隐藏该分支全部后代；解决人物数量巨大画布臃肿。
5. 定位到本人：一键聚焦当前登录用户在树谱中的位置，画布自动居中。

### 2.3 顶部工具栏功能
|功能项|需求描述|
|---|---|
|添加成员|弹出新增人物表单，录入完成后自动刷新树谱视图|
|搜索成员|弹窗输入姓名，搜索匹配人物，画布自动滚动、缩放到目标人物节点高亮|
|刷新视图|重新读取数据库，重绘全部树谱，修复连线错乱问题|
|导入JSON|读取族谱JSON文件，批量写入人物库，刷新树谱|
|导入Excel|解析族谱Excel模板，批量导入人物，数据校验后刷新视图|
|导出JSON|导出全家族原始人物数据，用于备份、迁移到其他族谱系统|
|导出分页PDF|分页切割世系图，文件大小可控，适配打印机打印吊线图|
|导出完整PDF|输出一张完整超长大图PDF，用于印刷世系挂画，增加文件大小提示|

### 2.4 人物节点过滤开关（重要，适配传统族谱）
三个独立开关，可自由组合勾选，实时生效，切换后画布立刻重绘：
1. 隐藏妻子：隐藏所有男性的配偶节点；
2. 隐藏女儿：隐藏本族女性后代（女儿）；
3. 隐藏女婿：隐藏女儿的配偶。

> 默认全部不开启，完整展示全部亲属；传统修谱用户可以一键开启，只显示本族男性族人。

### 2.5 特殊家谱业务场景适配
1. 一人多配偶：支持多妻/妾，各自子女分支独立连线；
2. 过继、兼祧：支持标记，血缘使用虚线；
3. 无子女：节点不向下生成连线；
4. 未婚无配偶：不渲染配偶卡片；
5. 离异、早夭：人物卡片可做标记标签。

### 2.6 与册谱模块联动
1. 在树谱点击人物卡片，支持【跳转到册谱】，直接定位到此人物的册谱文本记录；
2. 底层共用同一人物数据库：在册谱修改人物，树谱自动同步；树谱新增人物，册谱同步出现记录；**禁止两套独立数据存储**。

## 3、非功能需求
### 3.1 性能
1. 单棵族谱，500人物以内，画布渲染流畅；
2. 超过1000人物，提示用户建议开启分支折叠，避免卡顿；
3. 大数据量禁止一次性渲染全部节点，可实现可视区域懒加载。

### 3.2 兼容性
1. Web端：Chrome、Edge主流浏览器适配；
2. 移动端H5：支持触摸缩放、拖拽；小屏幕布局自适应。

### 3.3 异常处理
1. 父子关系循环错误（A的父亲是B，B的父亲是A）：检测循环数据，弹窗提示用户，不崩溃画布；
2. 关系缺失数据：缺少父亲ID的顶层祖先，放置在树谱最顶层；
3. 导入数据格式错误：给出错误明细，不污染现有族谱数据。

## 4、页面UI原型简要说明
1. 顶部：操作工具栏按钮组；
2. 主体区域：树谱可视化画布（滚动缩放区域）；
3. 底部Tab切换栏：【树谱 | 册谱 | 设置】，点击切换模块。

## 5、输入输出
- **输入源**：人物主表、配偶关联表、过继关系表
- **输出**：可视化树谱界面、JSON备份文件、PDF文件
- **跳转输出**：人物编辑弹窗、册谱页面定位

2. 过滤开关可以正确隐藏对应女性节点；

4. 导入导出后，重新打开树谱，人物关系完整无丢失；
5. 出现循环血缘数据，页面不崩溃，给出提示。
