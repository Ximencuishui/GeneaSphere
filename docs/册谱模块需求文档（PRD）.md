# 册谱模块需求文档（PRD）
文档版本：V1.0
所属项目：族谱Web网站项目
关联模块：树谱模块、人物数据模块、导入导出模块
> 核心原则：**册谱与树谱共用同一套人物底层数据库，册谱仅为文档式编排视图，不独立存储人物实体数据；人物数据一处修改，树谱、册谱两端同步更新**。
> 业务定位：复刻传统纸质家谱（线装族谱）书本形态，承载史料、传记、谱序，用于阅读、校对旧谱、导出PDF印刷成书。树谱负责看关系，册谱负责存档案、出书。

## 1、模块概述
### 1.1 产品目标
册谱模拟传统族谱的卷册书本格式，把家族人物、谱序、祖训、祠堂记、艺文、坟茔、迁徙记录等史料，按族谱体例编排，实现线上阅读、编辑、校对，并且可以导出PDF直接印刷装订实体家谱。

面向两类用户：
1. **修谱管理员**：录入谱序、凡例、人物大传，校对旧谱文字，排版，导出PDF交付印刷厂印刷家谱；
2. **家族普通成员**：查阅祖先完整生平、墓志铭、旧谱原文，阅读家族历史文献。

> 区分：树谱 = 看血缘结构图；册谱 = 读家族档案全书。

### 1.2 术语定义
- **卷/册**：册谱的卷宗分组，一本大谱分为多卷，例如卷一谱序、卷二世系录、卷三艺文志；
- **世录**：每个人物在册谱内的文字条目；
- **谱序**：家谱前言，修谱缘由、家族源流；
- **凡例**：修谱编写规则；
- **苏式排版**：苏洵格式，文字接续传记排版；
- **欧式排版**：世代格子对齐排版；
- **世系表开本（PR#1 新增）**：传统中式线装族谱版式，竖排自上而下、从右向左；每页并列 N 个世代成 N 列；右列顶"第 1 世"向左逐代推进；人物名红色楷体；顶端连接线 + 小圆圈；左下角竖排"族谱第 X 世至第 Y 世世系表"；页脚"第 X 页,共 Y 页"。最贴近老族谱开本，可直接送印。
- **房派**：家族分支，可按房派划分册谱内容；
- **附件史料**：祖训、祠堂记、墓志铭、艺文诗词、坟茔记录、迁徙记录。

## 2、功能需求
### 2.1 基础编排逻辑
1. 数据源：读取【人物主表、配偶关联表、传记附表、册谱卷宗配置表】；**不存储独立人物副本**。
2. 册谱由两类内容组成：
    ① 卷宗文档内容：谱序、凡例、祖训、祠堂记等非人物类史料；
    ② 人物世录内容：自动读取人物库数据，按辈分、房派自动生成人物条目。
3. 三种传统排版模式可切换
    - **苏式（苏洵体）**：段落接续式传记，文字流阅读，最贴合老家谱文本风格；
    - **欧式（欧式谱）**：世代格子对齐，世代层级清晰，兼顾少量表格化布局。
    - **世系表开本（PR#1 新增）**：传统中式线装族谱版式，用于印刷出书。竖排自上而下、从右向左；每页并列 N 个世代成 N 列；右列顶"第 1 世"向左逐代推进；人物名红色楷体；顶端连接线 + 小圆圈；左下角竖排"族谱第 X 世至第 Y 世世系表"；页脚"第 X 页,共 Y 页"。在卷宗配置中选 `layout: shixi_table` 即启用；可选 `page_gen_count`（每页世代数，默认 5）。
4. 排序规则：
    - 默认按照辈分从高到低；同辈内部按照长幼排行排序；
    - 支持切换：按房派分组输出，只输出选定房派的全部世录。

### 2.2 册谱卷宗管理（卷册结构管理）
管理员可以自定义整本族谱的卷结构，可新增、编辑、删除、调整卷顺序。
每一卷配置项：
1. 卷标题：例「卷一 谱序源流」「卷二 世系录」「卷三 艺文墓志」
2. 卷类型：
    - 文档卷：纯史料文本（谱序、祖训），手动编辑富文本；
    - 世录卷：**自动从人物库生成人物条目**，配置筛选条件：选哪些房派、是否包含女性、排版格式苏式/欧式。
3. 卷内内容编辑：富文本编辑器，支持文字、图片插入（老谱扫描件、祠堂图、坟图）。
4. 调整卷宗顺序，导出PDF会严格按照卷宗顺序输出。

> 示例完整册谱结构
> 卷一：谱序、凡例、修谱人员名单
> 卷二：世系录（男性族人，苏式排版）
> 卷三：闺秀录（女性族人传记）
> 卷四：艺文、墓志铭、祠堂记、坟茔志

### 2.3 人物世录条目渲染
从公共人物库拉取数据自动生成条目，不需要手动重复抄写人物。
#### 世录展示字段
基础信息：排行、姓名、字号、生卒、葬地、迁徙地点；
配偶信息：配偶姓名、籍贯、岳家信息；
子嗣信息：子女名单；
扩展文本：人物传记、功名、轶事；
附件：关联图片（画像、墓碑照片）。

> 对比树谱：树谱卡片只放极简字段；**册谱完整展示全部传记、葬地、大段文字**。

#### 过滤控制（和树谱过滤开关逻辑对齐）
世录卷可以配置过滤条件：
- 是否录入妻子传记；
- 是否录入女儿、女婿记录；
- 是否只输出指定房派分支；
- 是否包含夭折、过继人员。

### 2.4 页面交互功能
1. 书本翻页浏览：上一页 / 下一页；支持跳转指定卷、指定页码。
2. 全文检索：在整本册谱内搜索关键词，定位到卷、段落。
3. 人物跳转联动（和树谱双向打通）
    - 在册谱点击人物姓名弹窗：①编辑人物资料；②**跳转到树谱，该人物节点自动高亮居中**；
    - 在树谱点击人物卡片：可跳转册谱，自动定位到该人物的世录条目位置。
4. 增加批注：管理员可给段落增加批注备注，导出PDF可选择是否输出批注。
5. 只读模式：普通家族成员仅可阅读，不能修改卷宗内容。

### 2.5 导入导出
|功能|需求描述|
|---|---|
|导出PDF整本册谱|按照卷宗顺序完整输出PDF，用于印刷装订家谱；支持设置页眉页脚（族谱名称、卷名、页码）；支持选择是否输出图片、批注|
|导出单卷PDF|只导出选中某一卷内容|
|导出Word|可导出Word，供线下二次编辑排版|
|导入旧谱文本|粘贴老族谱扫描OCR文本，存入对应卷宗富文本编辑器；支持上传老谱图片嵌入卷宗|
|从JSON恢复册谱配置|卷宗结构配置可备份，切换设备可以恢复整套卷册编排方案|

### 2.6 特殊家谱业务适配
1. **过继、兼祧**：世录内标记过继来源，文本标注；
2. **多配偶（继配、妾）**：依次排列全部配偶传记信息；
3. **早夭/未成年**：配置开关，可选择是否在世录中收录夭折人物；
4. **女性记录**：可以单独设立「闺秀录」卷宗，集中记录女儿、夫人传记。

## 3、与树谱模块联动规则（重要约束）
1. 人物数据唯一来源：人物主表；册谱卷宗配置（卷标题、排版、筛选条件）独立存储在【册谱卷宗配置表】。
2. 人物新增/修改/删除：树谱、册谱同时生效；**修改人物，不需要再去册谱手动改一遍**。
3. 册谱的过滤条件，只控制「渲染输出哪些人物条目」，**不会修改底层人物数据库数据**。
4. 双向跳转：树谱 ↔ 册谱互相定位人物。
5. 数据边界：
    - 树谱只管图形连线；
    - 谱序、祖训、祠堂记这类非人物史料，**只存在册谱卷宗中，树谱不处理这类内容**。

## 4、非功能需求
### 4.1 性能
1. 500人物规模，世录卷渲染流畅；
2. 1000人以上大量人物，支持分页渲染世录，不一次性渲染全部DOM；
3. PDF导出大文档，增加进度提示，防止浏览器超时。

### 4.2 兼容性
1. Web端主流浏览器；H5移动端适配阅读模式；
2. PDF导出兼容打印，字体、繁体、生僻字不乱码。

### 4.3 异常处理
1. 卷宗引用已经删除的人物：自动跳过该人物，日志提示管理员；
2. OCR粘贴大量旧谱乱码文本：编辑器保留原始文本，做脏数据提示；
3. PDF导出超时：提示拆分成分多卷导出。

## 5、页面布局UI说明
1. 顶部工具栏：卷宗切换、搜索、导出PDF、导出Word；
2. 左侧边栏：卷宗目录导航（卷一、卷二……快速跳转）；
3. 主内容区：书本式阅读区域，展示册谱正文；
4. 底部Tab栏：【树谱 | 册谱 | 设置】和树谱共用底部Tab。

## 6、输入输出
- 输入源：人物主表、配偶关联表、传记附表、册谱卷宗配置表
- 输出：网页册谱阅读视图、PDF印刷文件、Word文档、卷宗配置备份JSON
- 跳转输出：人物编辑弹窗、跳转到树谱并定位人物节点

## 7、一期 / 二期迭代划分
### ✅一期（核心必做）
1. 卷宗新增、排序、富文本编辑；
2. 世录卷自动根据人物库生成苏式排版世录；
3. PDF整本导出；
4. 树谱与册谱双向跳转定位；
5. 世录卷基础过滤开关（是否包含女性、房派筛选）。

### ⏳二期迭代（可选）
1. 欧式排版；
2. 批注功能；
3. 册谱分享只读链接；
4. 页眉页脚自定义；
5. 打印预览模式。

## 8、验收标准
1. 修改人物基础信息、传记，册谱世录实时更新，和树谱数据完全一致；
2. 卷宗可以自由调整顺序，导出PDF顺序和目录顺序保持一致；
3. 世录卷过滤开关生效，不会修改底层原始人物数据；
4. 点击人物可以双向跳转树谱/册谱并且正确定位；
5. PDF导出输出完整文本、图片，适合线下印刷。
