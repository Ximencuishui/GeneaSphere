### 1.2 大族谱压力数据集

使用现有演示数据「朱熹族谱」或构造 1000 节点数据，要求：
- 至少包含 3 位多配偶男性；
- 至少 1 位男性有 3 位及以上配偶；
- 至少 2 位配偶各自带有 3 名及以上继子女。

### 1.3 边界数据集

| 场景 | 数据特征 | 验证目的 |
| --- | --- | --- |
| 单配偶 | 每位男性只有 1 位妻子 | 确保优化逻辑不破坏原有单配偶布局 |
| 无配偶 | 顶层祖先无配偶 | 确保无婚姻线绘制 |
| 多妻无子女 | 丈夫有 2 位妻子，均无子女 | 验证婚姻汇聚点与配偶排列 |
| 多妻同层密集 | 同一代际有 2 位以上多妻男性 | 验证同层婚姻线错开 |
| 深继子女子树 | 某妻子下方有 4 代继子女 | 验证子树宽度预留与扫描线推开 |

### 5.3 碰撞检测脚本

在浏览器控制台注入以下脚本，自动检测节点与边的违规：

```javascript
function checkOverlap(nodes) {
  for (let i = 0; i < nodes.length; i++) {
    for (let j = i + 1; j < nodes.length; j++) {
      const a = nodes[i], b = nodes[j];
      const dx = Math.abs(a.x - b.x) - (a.width + b.width) / 2;
      const dy = Math.abs(a.y - b.y) - (a.height + b.height) / 2;
      if (dx < 0 && dy < 0) console.error('重叠', a.id, b.id);
    }
  }
}
```
