## 1. 背景与目标

### 1.1 现状痛点

当前 `GenealogyTree.vue` 是一个**单视图 G6 画布**：

| 痛点 | 描述 | 影响 |
| --- | --- | --- |
| 宏观定位难 | 1000+ 节点时，用户拖拽/缩放后失去空间感，不知道"我现在在画布的哪个位置" | 反复拖拽，迷失方向 |
| 代际跳跃难 | 树深 20+ 代时，要从第 1 代滚到第 25 代需连续拖拽 20+ 次 | 体验割裂 |
| 视觉风格单一 | 只有"compact / detailed / portrait"三种密度模式，缺少"传统/现代"两套皮肤 | 品牌仪式感不足 |
| 节点过载 | 1000+ 节点时即使有 viewport culling，节点本身仍偏单调、缺少视觉层级 | 信息密度与可读性失衡 |

### 1.2 设计目标

**保留现有 G6 树作为主画布**，新增三个**辅助视图**与**一套风格皮肤**，把"单视图"升级为"三视图"：

1. **右下角鸟瞰图**（Mini-map / Overview）：始终可见的画布缩略图，让用户随时定位
2. **底部代际滑块**（Generation Slider）：以 1-N 代的横向刻度快速切换"以某代为根"展开
3. **风格皮肤切换**（Style Skin）：在「传统卷轴 / 现代简约」两套视觉风格中一键切换
4. **（可选）顶部时间轴**：横向时间维度条，可与代际联动（v1.1 规划）

> 设计原则：**不破坏现有 G6 实现**（避坑"子路径白屏 + 重库首屏白屏"），所有增强以"叠加层 + 独立组件"形式接入，**允许单独回滚**。

## 4. 详细设计

### 4.1 鸟瞰缩略图（Mini-map）

#### 4.1.1 功能

- **画布全貌预览**：用 Canvas 2D 把 G6 节点位置按比例绘制为小色块（不绘制边）
- **当前视口指示**：金色矩形框 (`#C9A96E` 2px stroke + 8% 透明填充) 标出 G6 主画布当前可视区域
- **点击/拖拽跳转**：鼠标点击 / 拖拽缩略图 → 主画布视口平滑移动到对应位置
- **悬浮折叠**：标题栏右侧"−"按钮可折叠为单行（仅留标题 + 当前视口中心代际），节省右下空间
- **自适应性**：节点数 < 50 时自动隐藏（小于主画布一屏可显示）

#### 4.1.2 视觉规范

| 元素 | 样式 |
| --- | --- |
| 容器 | 240×180，圆角 8px，背景 `rgba(255,255,255,0.95)`，阴影 `0 4px 12px rgba(0,0,0,0.12)` |
| 标题栏 | 高度 24px，左侧 11px 文字"鸟瞰图" `#7F8C8D`，右侧"−"按钮 |
| 节点色块 | 按代际分色（1代=深棕 `#5D4037`，逐代渐淡到 30代=米色 `#F5F0E8`），男蓝 `#90CAF9` / 女粉 `#F48FB1` 覆盖 |
| 主传承节点 | `#C9A96E` 金色填充 + 0.5px 描边 |
| 视口框 | `#C9A96E` 实线 2px，填充 `rgba(201,169,110,0.08)` |
| 折叠态 | 仅显示一条横向 2px 金色短线段标识"主传承路径"位置 |

#### 4.1.3 数据来源

- **节点位置**：`G6Graph.getElementPosition(id)` 已经在 `performViewportCulling` 中用到；缩略图通过 `G6Graph.getNodeData()` + 一次 `getElementPosition` 批量获取
- **视口位置**：`G6Graph.getViewportCenter()` + `getSize()`，已在 culling 中用到
- **节流**：缩略图每 200ms 重绘一次（rAF 节流），避免与主画布拖拽事件抢性能

#### 4.1.4 交互流程

```
用户在主画布拖拽 → aftertransform 事件触发
  ├─ 200ms 内多次触发则合并 → 200ms 后统一重绘缩略图
  └─ 重绘时：
      1. 清除画布
      2. 计算全画布 bbox（minX, minY, maxX, maxY）
      3. 按比例映射到 240×180
      4. 遍历节点 → 画 3×3 圆点（按代际/性别配色）
      5. 计算视口矩形在缩略图坐标 → 画金色框
```

```
用户点击/拖拽缩略图：
  1. onMouseDown 记录起点（缩略图坐标）
  2. onMouseMove 计算偏移量 → 转换为画布坐标 delta
  3. 调 G6Graph.translateTo(dx, dy, animate=true)
  4. 释放鼠标 → 触发主画布 aftertransform → 缩略图自动重绘
```

### 4.2 代际滑块（Generation Slider）

#### 4.2.1 功能

- **横向代际刻度**：根据后端返回的最大世代数（朱熹族谱约 30 代）渲染 1-N 个均匀刻度
- **当前选中代**：用一根金色滑块（24px 高、4px 宽）指示
- **点击刻度** → 主画布立即重新计算布局，**以该代为根**展开（自动 collapse 其他分支）
- **拖动滑块** → 主画布实时更新（rAF 节流）
- **双击刻度** → 恢复"完整树"展开（取消代际聚焦）

#### 4.2.2 视觉规范

| 元素 | 样式 |
| --- | --- |
| 容器 | 32px 高，左 16px 起始，背景 `rgba(250,248,245,0.96)`，上边框 1px `#E4E7ED` |
| 刻度文字 | 11px 字号，`#7F8C8D`；每 5 代显示数字（"1 5 10 15 20 25 30"），其余只显示短刻度 |
| 短刻度线 | 8px 高 × 1px 宽，`#D0D0D0` |
| 长刻度线 | 12px 高 × 1px 宽，`#A1887F` |
| 滑块 | 24px 高 × 4px 宽，`#C9A96E`，左右各带 6px 圆形端点 |
| 选中代高亮 | 刻度数字 `font-weight: 600`，颜色 `#5D4037` |

#### 4.2.3 数据来源

- **最大世代数**：从后端 `getClanFullTree` 返回的 `totalGenerations` 字段（待确认是否已有该字段，无则前端从树遍历推算）
- **当前选中代**：默认 = 1（从始祖根开始）；用户操作后由滑块维护
- **以某代为根**：调用 `treeApi.getSubTree(personIdOfGenerationX)` 拉取该代的子树，替换主画布数据源

#### 4.2.4 交互流程

```
用户点击"18代"刻度：
  1. 后端响应：getSubTree(personId_at_18)  →  返回该代为根的子树
  2. 主画布执行 fetchTreeData → transformToG6Data → initGraph
  3. 缩略图自动重绘
  4. 滑块定位到"18代"
  5. 顶部导航栏面包屑追加「/ 第 18 代」标记

用户双击"18代"刻度：
  → 恢复 fetchTreeData(rootId='1') 全树模式
```

### 4.3 风格皮肤切换（Style Skin）

#### 4.3.1 功能

在工具栏右侧加一个下拉，**两套皮肤**：

| 皮肤 | 名称 | 描述 |
| --- | --- | --- |
| `traditional` | 传统卷轴 | 米黄背景 + 圆形印章节点 + 墨线贝塞尔连线 + 楷体字 |
| `modern` | 现代简约（默认） | 当前实现，米白背景 + 矩形节点 + 灰色直线（保留所有现有逻辑） |

#### 4.3.2 视觉规范

**`modern` 皮肤 = 现有实现，无需任何改动**

**`traditional` 皮肤 节点细节**：

| 元素 | modern | traditional |
| --- | --- | --- |
| 节点背景 | 矩形，性别色 | 圆形印章，男蓝 `#1976D2` / 女粉 `#C2185B` 70% 透明 |
| 节点边框 | 1.5px 性别色 | 已故：`#A1887F` 实线 1.5px；在世：性别色虚线 1.5px |
| 头像 | 圆角方块 | 圆形（圆周嵌入"阴阳鱼"风格：上半男色 / 下半女色） |
| 文字 | 无衬线 13-14px | 楷体（`KaiTi, STKaiti, serif`）12-13px，竖排"姓+名" |
| 已故标识 | 棕边 | 在节点右下角加一枚红色篆刻风方章（"故"字） |
| 主传承高亮 | 金色边框 + 阴影 | 在节点外圈加 2px 金色光环（`stroke + shadowBlur=8`） |
| 父子连线 | `cubic-horizontal` 灰色 | `cubic-horizontal` 渐变黑色（`#3E2723` 起点 → 0.4 透明终点） |
| 配偶连线 | 红粉实线 | 朱砂红 `#C62828` 实线 + 0.4 透明（不变） |
| 背景 | `#FAF8F5` 纯色 | `linear-gradient(180deg, #FBF6EC 0%, #F5F0E8 100%)` + 浅色宣纸纹理（SVG 噪声） |

#### 4.3.3 切换实现

- 风格状态存到 `genealogyStore.styleSkin: 'modern' | 'traditional'`
- `initGraph` 中根据 `styleSkin` 走两个不同的 node style 配置分支
- 切换时调 `graph.refresh()` 重绘（不要 destroy + init，避免进度条闪烁）
- 默认值跟随用户上次选择（localStorage 持久化）

## 6. 数据流

```
User 拖拽/缩放主画布
  └─ G6 aftertransform
       ├─ 主画布 performViewportCulling（既有）
       └─ emit 'viewport-changed' → TreeMinimap 监听 → 200ms 后重绘

User 点击鸟瞰图
  └─ TreeMinimap onClick
       └─ emit 'pan-to' { x, y } → GenealogyTree
            └─ g6Graph.translateTo(x, y, { animate: true })

User 点击代际滑块
  └─ TreeGenerationSlider onChange(generation)
       └─ emit 'focus-generation' → TreePage
            └─ fetchTreeData(personIdOfGen) → 重新 initGraph

User 切换皮肤
  └─ StyleSkinPicker onChange('traditional' | 'modern')
       └─ genealogyStore.setStyleSkin(...)
            └─ GenealogyTree watch styleSkin → g6Graph.refresh()
```

**Store 扩展**（`apps/web/src/stores/genealogy.ts`）：

```ts
// 现有
state: { treeData, selectedNode, viewMode, mainLineage, totalPersons }
// 新增
state: { styleSkin: 'modern' | 'traditional' }
       { focusedGeneration: number | null }
       { minimapCollapsed: boolean }
```

## 7. 技术实现要点

### 7.1 G6 兼容

- **不引入新 G6 扩展**：三视图均不直接调用 G6 的 `minimap` plugin（避免 preset 副作用，参考《G6 v5 子路径导入画布白屏三层修复技能》）
- **鸟瞰图用原生 Canvas 2D**：独立组件，从 `GenealogyTree` 通过 `defineExpose` 暴露 `getNodesForMinimap()`、`getViewportForMinimap()` 两个方法
- **缩略图坐标映射**：用 G6 已有的 `getElementPosition` + 一次扫描算 bbox，不调 G6 的 layout API

### 7.2 性能

| 项 | 措施 |
| --- | --- |
| 鸟瞰图重绘 | rAF + 200ms 节流 + 仅节点位置变化时重绘（视口独立） |
| 代际滑块拖动 | rAF + 60ms 节流，避免每 16ms 触发后端请求 |
| 皮肤切换 | 仅调 `g6Graph.refresh()`，**不重建 graph**；node style 走 `updateElementData` 局部更新 |
| 组件体积 | 三个新组件均 < 10KB gzipped；总体主包增量 < 30KB |

### 7.3 已有约束遵守

- **G6 子路径导入**：[GenealogyTree.vue:62-66](apps/web/src/components/GenealogyTree.vue) 的子路径 register 流程不变
- **导航栏规范**：[《家族树固定顶部导航栏规范》](家族树固定顶部导航栏规范) 要求 48px 固定导航栏必含「返回上一页 / 返回首页 / 家族名称 / 传承徽章 / 聚焦传承」—— 不变
- **工具栏规范**：[《家族树工具栏单行紧凑布局规范》](家族树工具栏单行紧凑布局规范) 要求 ≤ 40px 单行、禁用 `@media (max-width: 1200px) flex-direction: column`—— 风格皮肤下拉放在工具栏右侧 64px 宽内
- **节点姓名字段**：[《家族树节点姓名字段兼容规范》](家族树节点姓名字段兼容规范) `full_name / name / label` 三选一读取—— 皮肤切换不影响
- **进度条**：[《长耗时渲染需添加分阶段进度条》](长耗时渲染需添加分阶段进度条) 4 阶段（fetch/parse/render/finalize）流程不变

### 7.4 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1440px | 鸟瞰图 240×180 + 滑块 32px + 工具栏单行 |
| 1200-1440px | 鸟瞰图 200×150（折叠态默认收起） |
| 992-1200px | 鸟瞰图可隐藏（工具栏加"显示鸟瞰图"开关） |
| < 992px | 滑块隐藏（用 `display: none`），仅保留鸟瞰图 + 主画布 |

> 注：此断点**不通过 flex-direction 实现**，符合工具栏规范。

## 9. 风险与对策

| 风险 | 等级 | 对策 |
| --- | --- | --- |
| 鸟瞰图重绘与 G6 aftertransform 互相触发死循环 | 中 | 缩略图拖拽时**不触发**主画布 translateTo 时序中带 `source: 'minimap'` 标记，缩略图重绘跳过该次 |
| 代际滑块拖动频繁触发后端 | 中 | 60ms 节流 + 拖动停止 200ms 后再发请求（debounce） |
| `traditional` 皮肤使用楷体在 Windows 无衬线降级 | 低 | 字体栈 `KaiTi, STKaiti, "Songti SC", "SimSun", serif`，并加 `font-display: swap` |
| G6 的 `translateTo` API 在子路径下是否可用 | 中 | POC 阶段先验证；若不可用回退到 `graph.fitView()` + `graph.setItemState` |
| 宣纸纹理 SVG 噪声影响加载 | 低 | 内联 SVG 噪声（`<feTurbulence>`），不外链图片 |
| 鸟瞰图与详情面板（420px）冲突 | 低 | 详情面板打开时，鸟瞰图自动 `right: 16px → 16+420+16 = 452px`（CSS 变量切换） |
