### 地图选点

需求来自《寻根路（xungenlu.cn）族谱管理员后台需求文档 v2.0（整合版）》影像管理：拍摄地点应支持地图选点，并自动补全已有 POI。当前影像地点仍是文本字段 `taken_location`，仓库没有可复用的地图或 POI 选点组件。

已实现（2026-11-15）。入口：家族后台 → 历史影像 → 影像库 → 编辑影像。地点框会按关键词补全本族未删除影像里的拍摄地点，接口是 `GET /api/admin/media/:clanSlug/locations`。旁边用项目已有的 Leaflet 和高德瓦片点选；点选后若能解析出地名，写入 `taken_location`。库里没有经纬度列，坐标不会单独保存。环境里没有高德 Web 服务 key，所以地名解析走 OpenStreetMap 的逆地理编码，解析失败时仍可从本族地点里点选或手填。

### ZIP 下载

需求来自《寻根路（xungenlu.cn）族谱管理员后台需求文档 v2.0（整合版）》影像管理：批量下载应打包为 ZIP（异步处理，完成后通知）。当前批量打包下载未做，仓库没有 zip 库，也没有为此新增依赖。

已实现（2026-11-15）。入口：影像库勾选后点「打包下载」。接口 `POST /api/admin/media/:clanSlug/batch-zip`，body `{ ids: number[] }`，单次最多 50 条；下载地址 `GET /api/admin/media/:clanSlug/zips/:filename`，会再校验本族。只打包本族未删除影像，文件来自本地 `/media/` 或该影像自己的存储 key。远程对象只有现有存储服务能按 key 读到内容时才放进压缩包，读不到的会跳过并在结果里说明。打包完成后给当前管理员一条系统通知「影像打包完成」。服务端依赖为 `archiver`。

### 封面展示页

需求来自《寻根路家谱管理员后台需求文档 v1.1》影像审核，并在 v2.0 影像管理中延续：优质照片可设为聚落封面，用于聚落页面展示。当前审核里「设为封面」只把 `is_cover` 写成 true；聚落页和村寨展示页没有读取该标记，也没有新做封面展示页。

已实现（2026-11-15）。仓库没有单独的聚落页，封面展示加在公开家族页 `/clans/:id` 的「聚落封面」区块。影像库页头有「查看聚落封面」可直接打开。接口 `GET /api/media/clan/:clanId/covers`，只返回该族 `is_cover = true`、未删除、审核已通过或没有审核记录的影像。设封面仍只在影像审核里，并且仍只允许村寨风貌或祭祀活动。
