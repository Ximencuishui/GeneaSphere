# Round 4 — 异常与性能实测报告

> 测试时间：2026-08-01；工具：browser-use MCP + 后端 API 请求。

## Token 与异常边界

| 场景 | 期望 | 实际 |
|---|---|---|
| 无 Authorization | 401 | ✅ 401 |
| 空 Bearer | 401 | ✅ 401 |
| 破损 Token 格式 | 401 | ✅ 401 |
| 过期 Token | 401 | ✅ 401 |
| `alg=none` Token | 401 | ✅ 401 |
| 浏览器携带无效 Token 访问受保护页 | 跳转 `/login` | ✅ |

成员 Token 调用管理员 API：members、announcements、logs、qrcodes 均 403；管理员 Token 调用对应接口均 200。

## 性能基线

| 页面/接口 | 首次实测 |
|---|---:|
| dashboard | 2775ms（含首次预热） |
| members | 1640ms |
| announcements | 1748ms |
| logs | 1039ms |
| 朱小小子树（9 节点） | 897ms |
| 完整族树 | 4504ms |

## 并发登录

6 个并行 demo-login 请求全部返回 HTTP 201，总耗时约 `2936ms`。

## 环境稳定性记录

测试中数据库 SSH 隧道/服务曾因 Prisma 数据库连接超时导致进程退出，重建隧道并重启服务后恢复。该事件说明生产部署仍需完成连接池、健康检查、自动重启和告警验证。

## 结论

已执行的异常与性能用例均通过，但本轮是基线验证，不是完整 k6 压测或生产容量证明。完整族树接近 5 秒，应纳入上线前性能观察与优化项。
