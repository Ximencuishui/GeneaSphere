# 族谱树视觉效果优化

## Context

验证流程中发现族谱树页面存在多个视觉和体验问题：布局方向与边类型不匹配导致连线走向错误、控制台报错、动画缺失、页面标题不准确、登录后路由跳转失败。用户反馈"前端展现不是最佳视觉效果"，需要全面修复。

---

## 修复项

### 1. 布局方向与边类型匹配（视觉核心问题）

**问题**：`layoutDirection` 默认 `'TB'`（纵向），但 edge type 硬编码为 `'cubic-horizontal'`（横向三次贝塞尔），导致纵向布局下连线从节点右侧出发而非底部，视觉不协调。`cubic-vertical` 从未注册。

**文件**：`apps/web/src/components/GenealogyTree.vue`

**修改**：
- 在 `loadG6Runtime()` 中新增注册 `cubic-vertical` edge（import `@antv/g6/esm/elements/edges/cubic-vertical`）
- 将 edge `type` 从硬编码 `'cubic-horizontal'` 改为根据 `layoutDirection.value` 动态选择：`'TB' → 'cubic-vertical'`，`'LR' → 'cubic-horizontal'`
- 同步调整 `labelPlacement` / `labelOffset` / `sublabelPlacement` / `sublabelOffset` / `iconOffset` 等位置参数，使其在 TB 模式下标签位于节点下方而非右侧

### 2. `applyZoomLOD` 竞态条件修复

**问题**：`aftertransform` 事件在 graph viewport 未就绪时触发，`g.getZoom()` 内部访问 undefined 的 viewport 抛 `TypeError`。

**文件**：`apps/web/src/components/GenealogyTree.vue`（约 L857-874）

**修改**：在 `applyZoomLOD` 函数开头增加 try-catch 包裹 `g.getZoom()` 调用，或增加更严格的守卫（检查 `g.getViewportCenter` 也可用）。

### 3. 注册 `fade` 动画扩展

**问题**：G6 子路径按需加载绕过了 preset，`fade` 动画未注册，节点展开/收起缺少过渡动画。

**文件**：`apps/web/src/components/GenealogyTree.vue`（`loadG6Runtime` 函数）

**修改**：
- import `@antv/g6/esm/animations/fade`
- 在 register 区域添加 `register('animation', 'fade', Fade)`

### 4. 演示登录写入 `demo_clan_name`

**问题**：后端 `demoLoginInternal` 返回 `demoClanId` / `demoClanSlug` 但不返回 clan name，前端 `applyDemoLogin` 无法写入 `demo_clan_name`，页面标题显示回退值 "族谱全景"。

**文件**：
- `apps/server/src/auth/auth.service.ts`（L76-96, L128-133）
- `apps/web/src/stores/auth.ts`（L31-36, L140-152）
- `apps/web/src/components/landing/DemoRoleModal.vue`（L23-28）

**修改**：
- 后端 `getDemoClanWithSlug()` 的 select 增加 `name` 字段
- 后端 `demoLoginInternal` 返回值增加 `demoClanName`
- 前端 `DemoLoginResponse` 接口增加 `demoClanName: string | null`
- 前端 `applyDemoLogin` 中写入 `localStorage.setItem('demo_clan_name', data.demoClanName)`

### 5. 修复登录后路由跳转

**问题**：`LandingPage.vue` 跳转到 `/zupu/${slug}/dashboard`，但路由配置中 dashboard 是 `/zupu/:slug` 下的空路径子路由（`path: ''`），完整路径应为 `/zupu/${slug}`。

**文件**：`apps/web/src/views/LandingPage.vue`（L54）

**修改**：将 `router.push('/zupu/${slug}/dashboard')` 改为 `router.push('/zupu/${slug}')`

---

## 验证方式

1. 重启后端 + 前端 dev server
2. 浏览器一键登录 → 验证跳转无路由警告
3. 导航到 `/tree/4` → 验证：
   - 控制台无 error / fade 警告
   - 纵向布局下连线从节点底部出发（cubic-vertical）
   - 切换为横向布局后连线从节点右侧出发（cubic-horizontal）
   - 页面标题显示 "朱熹族谱（演示）· 族谱树"
   - 节点展开/收起到有淡入淡出过渡
